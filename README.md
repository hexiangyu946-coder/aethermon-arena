## ✨ 核心特性
- **🗺️ 12 张无缝连通开放世界大地图**：从微风始源镇、星辰桌台市、大锅琉璃湖到第零区星渊巨坑，支持步行跨界与飞翔出租车快传。

- **💾 多重账号记忆与云端存档**：内置 30 天 Cookie + IndexedDB 免密自动恢复登录、加密存档码导入导出，以及 GitHub 私有 Gist 云端同步。
- **🌐 四大联机对战模式**：跨网 WebRTC 点对点直连、同机多窗口广播秒连、双人同屏热座、天梯排位匹配。
